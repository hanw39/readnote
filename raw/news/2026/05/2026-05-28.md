## Zero Trust for AI agents【⭐⭐】
**来源：** Claude Blog
**链接：** https://claude.com/blog/zero-trust-for-ai-agents
**关键词：** 企业AI安全, Zero Trust, AI Agent安全框架, 威胁建模

### 摘要
Anthropic 发布了一份面向企业安全负责人的 AI Agent 零信任部署框架。核心观点：前沿 AI 模型已经把漏洞从发现到利用的时间窗口从"月级"压缩到"小时级"，这对部署 Agent 的组织尤其危险——Agent 的自主决策能力让传统访问控制失效。框架分 Foundation、Advanced、Optimized 三个层级，对应的组织安全成熟度不同。具体覆盖了身份验证、权限范围、沙箱隔离、输入输出控制、内存保护，以及被攻击者利用 prompt injection、工具投毒、memory poisoning 等威胁场景的防御方案。还提到了 Agentic SOAR（安全编排自动化响应），目的是让防御速度匹配 AI 攻击者的速度。

## How CodeRabbit used Claude to build an agent orchestration system【⭐⭐】
**来源：** Claude Blog
**链接：** https://claude.com/blog/how-coderabbit-used-claude-to-build-an-agent-orchestration-system
**关键词：** CodeRabbit, Agent编排, 代码审查, 规划层

### 摘要
AI 代码审查平台 CodeRabbit 分享了他们如何用 Claude 构建了一个 Agent 编排系统。核心问题：AI 生成的代码虽然编译通过、测试通过，但往往不符合业务预期——因为开发者默认 AI 也理解他们脑子里的隐含知识，不会把需求写清楚。CodeRabbit 的做法是在代码生成之前插入一个"规划层"，用多个 Claude 模型协作分析需求、暴露假设，生成一份结构化的 PRD（产品需求文档），再交给 Claude Code 执行。创始人 David Loker 的比喻：代码生成越便宜，走错方向就越贵。目前 CodeRabbit 每周审查 200 万个 PR，服务 15000+ 客户。

## Using LLMs to secure source code【⭐⭐】
**来源：** Claude Blog
**链接：** https://claude.com/blog/using-llms-to-secure-source-code
**关键词：** 代码安全, 漏洞发现, 威胁建模, 自动化修复

### 摘要
Anthropic 分享了用 LLM（特别是 Claude Opus）做代码安全审计的最佳实践流程。核心发现：**发现漏洞已经很容易并行化了，瓶颈转移到了验证、分类和修复阶段**。截至 2026 年 5 月 22 日，Anthropic 在开源软件扫描中已披露 1596 个漏洞，但只有 97 个被修复（约 6%）。流程分六步：威胁模型→沙箱环境→漏洞发现→验证→分类→修复。重点强调：威胁模型做不好是 false positive 的最常见原因——模型不知道哪些输入是可信的就会乱报。建议在首次扫描时多次跑循环，后续定期或在代码变更时继续扫描。

## Coding agents in the social sciences【⭐⭐】
**来源：** Anthropic Research
**链接：** https://www.anthropic.com/research/coding-agents-social-sciences
**关键词：** 社会科学, AI采纳, 编码Agent, 研究不平等

### 摘要
Anthropic 发布了面向定量社会科学研究者的 AI 编码 Agent 使用调查报告（2026 年 2-3 月，1260 名受访者）。核心发现：(1) 81% 的社会科学家尝试过 AI 聊天机器人，但只有 20% 每周使用编码 Agent（如 Claude Code、Codex）。(2) 使用率差异极大——男性名字的研究者使用率是女性的两倍；顶尖大学的研究者比其他学校高 40%。(3) 使用编码 Agent 的研究者提交的工作论文和基金申请更多，但这可能反映早期采用者的自身差异。(4) Claude Code 是使用最广泛的 Agent 工具（86% 的用户使用）。这是 Anthropic 一个更大规模追踪研究的基线调查，后续还会进行随机实验（给研究者提供 Claude Code 权限并观察产出变化）。
