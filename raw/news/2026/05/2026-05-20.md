## Google Gemini CLI 正式退役，全面转向 Antigravity CLI【⭐⭐⭐】
**来源：** Google AI  
**链接：** https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/  
**关键词：** Gemini CLI, Antigravity CLI, Google I/O 2026, 终端工具, Go

### 摘要
Google 宣布 Gemini CLI 将停止服务，全线迁移至 Antigravity CLI。这是一次从社区驱动的终端工具到统一 agent-first 平台的战略收束。

几个关键数据：Gemini CLI 去年发布以来，GitHub 获 10 万+ star，合并了 6000+ PR，有数百贡献者。但 Google 认为用户的 workflow 已经超越了 2025 年的单体 agent 范式——现在需要的是多个 agent 协作解决复杂问题。

Antigravity CLI 的核心变化：
- **用 Go 重写**：更快的执行速度
- **异步工作流**：后台协调多个 agent 处理大规模重构或研究，不锁终端
- **统一架构**：与 Antigravity 2.0 桌面应用共享同一 agent harness，核心改进自动同步

保留的关键功能：Agent Skills、Hooks、Subagents、Extensions（以 Antigravity plugins 形式）。

时间线：
- 即日起：Antigravity CLI 面向所有人开放
- **2026年6月18日**：Gemini CLI 和 Gemini Code Assist IDE 插件停止为个人/免费用户提供服务
- 企业用户（Gemini Code Assist Standard/Enterprise license）不受影响
- Gemini Code Assist for GitHub 同样受影响，6月18日后不再接受新仓库安装

这次迁移本质上和去年 Anthropic 收购 Stainless、Claude Code 逐渐成为主线是一个逻辑——各家都在把终端 AI 工具从实验性产品线收束到统一开发平台，2026 年的主题词是「收敛」。

## Google Tensor SDK 进入 Beta，LiteRT 统一终端推理【⭐⭐⭐】
**来源：** Google AI  
**链接：** https://developers.googleblog.com/google-tensor-sdk-beta-with-litert/  
**关键词：** Tensor ML SDK, LiteRT, Pixel 10, TPU, 端侧AI, Gemma 3

### 摘要
Google Tensor ML SDK 从 Experimental Access Program (EAP) 毕业进入 Beta。这个 SDK 让开发者可以直接在 Pixel 10 系列设备的 Google Tensor TPU 上部署高性能 ML 模型。

Beta 版的两大亮点：

**1. 与 LiteRT 统一工作流**
- LiteRT 是 Google 的边缘部署框架，抽象了底层 vendor-specific SDK
- 开发者可以用 LiteRT Torch 把 PyTorch 或 TFLite 模型编译成 TPU 优化的二进制
- 通过 Play Feature Delivery 分发 runtime 库，用 AI Packs 打包模型
- 支持 fallback：TPU 不可用时自动切到 CPU/GPU

**2. 100+ 模型花园**
- 包含经典 ML 模型和 Gemma 3 1B 等生成式 AI 模型
- 已编译模型可直接从 LiteRT Hugging Face 社区下载
- 应用场景：小语言模型（Function Gemma、EmbeddingGemma）、内容创作、视觉理解、语音识别

支持设备：Pixel 10、Pixel 10 Pro、Pixel 10 Pro XL、Pixel 10 Pro Fold。

这个发布配合 Google I/O 2026，加上同天发布的 LiteRT-LM 文章（端侧 GenAI 加速），Google 在「端侧 AI」上打了一套组合拳。和 Apple Intelligence 的路径不同——Google 选择把 TPU 直接开放给第三方开发者，而非仅用于自家功能。

## KPMG 与 Anthropic 达成全球战略联盟，Claude 进入 27.6 万员工日常【⭐⭐⭐】
**来源：** Anthropic News  
**链接：** https://www.anthropic.com/news/anthropic-kpmg  
**关键词：** Anthropic, KPMG, Claude, Digital Gateway, 企业合作, 私募股权

### 摘要
KPMG——全球最大的专业服务公司之一，覆盖 138 个国家的审计、税务、法律和咨询服务——宣布与 Anthropic 建立全球联盟，将 Claude 嵌入核心业务。

几个重要层面：

**Digital Gateway 平台整合**
Claude Cowork 和 Managed Agents 直接嵌入 KPMG 的 Digital Gateway（基于 Microsoft Azure），这是 KPMG 给客户交付工作的主平台。KPMG 美国税务副主席 Rema Serafi 说：以前帮客户建一个适应税法变化的 AI agent 要几周，现在几分钟。

**全员部署 Claude**
KPMG 全球 27.6 万+ 员工全部获得 Claude 使用权。此前 KPMG 在美国的 AI and Data Labs 已经内部试用了两年。

**私募股权方向**
Anthropic 指定 KPMG 为私募股权领域的首选合作伙伴。KPMG 推出了 PE 专项产品 KPMG Blaze，可嵌入 Claude Code 帮助被投公司快速现代化老旧 IT 系统。

**网络安全**
双方团队将用 Claude 在关键系统中发现和修复漏洞，工作遵循 KPMG 的 Trusted AI 框架。

**人机协作研究**
KPMG 与 UT Austin McCombs 商学院联合研究发现：AI 部署的最大价值不在于技术本身，而在于人类如何运用判断力、优化工作流、评估输出、与 AI 共同决策。

**💡 横向观察：**
Anthropic 在企业合作上攻势猛烈。上周刚宣布收购 Stainless（SDK/MCP server 工具链），这周 KPMG 全员上车。加上之前的 PwC 3 万人认证计划、Gates 基金会 2 亿美元合作，Anthropic 在专业服务行业的渗透速度非常快。相比之下，Google 这周重心在 I/O 2026 的开发者生态（Antigravity CLI + Tensor SDK），而 OpenAI 这轮相对安静。
