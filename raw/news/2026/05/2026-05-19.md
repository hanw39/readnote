## New in Claude Managed Agents: self-hosted sandboxes and MCP tunnels【⭐⭐⭐】
**来源：** Claude Blog
**链接：** https://claude.com/blog/claude-managed-agents-updates
**关键词：** Claude Managed Agents, Self-hosted Sandbox, MCP Tunnels, Enterprise

### 摘要

Claude Managed Agents 迎来重要更新，现在支持两个核心企业级能力：

**1. 自托管沙箱（Self-hosted Sandbox，公开 Beta）**
Agent 工具执行可以跑在你自己的基础设施上，而 Anthropic 仍负责编排、上下文管理和错误恢复。敏感文件、包和服务不出你的网络边界，审计日志和网络策略复用已有设施。首批合作伙伴包括 Cloudflare、Daytona、Modal、Vercel。

- **Cloudflare** — 微VM隔离，零信任密钥注入，支持代理审计出口流量
- **Daytona** — 可组合的长运行沙箱，支持 SSH 或预览 URL 访问，可暂停/恢复
- **Modal** — 专为 AI 负载设计，支持 CPU/GPU 按需分配，百级并发
- **Vercel Sandbox** — VM 级安全 + VPC 对等 + BYOC，凭证在网络边界注入

合作案例：Clay 的 GTM 工程 agent "Sculptor" 基于 Managed Agents + Daytona 运行；一家金融 AI 平台用 Vercel Sandbox 处理专有数据。

**2. MCP Tunnels（MCP 隧道，Research Preview）**
Agent 可以通过隧道访问私有网络内的 MCP 服务器——内部数据库、私有 API、知识库、工单系统都变成工具的调用目标。部署一个轻量级网关做单向出站连接，不需要入站防火墙规则或公网端点，端到端加密。同时支持 Managed Agents 和 Messages API。

整体来看，这标志着 AI Agent 从「纯云端执行」向「企业混合架构」迈出关键一步——模型编排仍在 Anthropic，工具执行落在用户可控环境里。对于有合规和数据驻留要求的企业，这直接消除了一个关键障碍。

## KPMG integrates Claude across its core business and workforce of more than 276,000【⭐⭐⭐】
**来源：** Anthropic News
**链接：** https://www.anthropic.com/news/anthropic-kpmg
**关键词：** Anthropic, KPMG, Enterprise, Claude Cowork, Managed Agents

### 摘要

Anthropic 和 KPMG 宣布全球战略联盟，这是 Claude 迄今为止规模最大的企业级部署。

**核心细节：**
- KPMG 将 Claude 嵌入数字网关平台 Digital Gateway（基于 Microsoft Azure），首发税务和法务客户工具
- 全球 276,000+ 员工均可使用 Claude
- Anthropic 指定 KPMG 为私募股权的首选合作伙伴，共同为 PE 投资组合公司构建 Claude 驱动的产品

**Claude Cowork + Managed Agents 深度集成**
Digital Gateway 中嵌入 Claude Cowork 和 Managed Agents 后，KPMG 的专业人员可以直接在平台内构建新的 AI 能力。以前帮客户适配税法变更的 agent 需要几周开发，现在几分钟即可完成。

**安全领域扩展**
联盟还将 Claude 应用于网络安全——帮助发现和修复关键系统中的漏洞，工作由 KPMG 的 Trusted AI 框架指导。

**"Human in the loop" 实证**
KPMG 与 UT Austin McCombs 商学院的联合研究表明，AI 部署的价值不仅取决于技术本身，更取决于人类如何行使判断、塑造工作流、评估输出并与 AI 共同决策。

**连续动作**
这是 Anthropic 在一周内宣布的第三项重大企业合作——此前已宣布收购 Stainless（SDK/MCP 工具）和与 Gates Foundation 的 2 亿美元合作。
