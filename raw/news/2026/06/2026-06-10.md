## Claude Fable 5 和 Claude Mythos 5 发布【⭐⭐⭐】
**来源：** Anthropic News
**链接：** https://www.anthropic.com/news/claude-fable-5-mythos-5
**关键词：** Claude Fable 5, Mythos 5, Mythos-class, 前沿模型, 安全护栏, Project Glasswing, 生物医药, 软件工程

### 摘要

Anthropic 正式发布 Claude Fable 5 和 Claude Mythos 5两个新模型。Fable 5 是 Mythos 级别的模型（与 Mythos 同底模），但加了安全护栏面向大众开放；Mythos 5 则在部分领域解除护栏，目前仅通过 Project Glasswing 与美国政府合作提供给网络防御团队使用。

**价格：** $10/M input tokens, $50/M output tokens — 不到 Mythos Preview 的一半。

**核心能力亮点：**

- **软件工程：** Fable 5 是当前 SOTA。Stripe 测试中，在一个 5000 万行 Ruby 代码库里，Fable 5 一天完成了原本需要团队两个多月的手动迁移。Cognition FrontierCode 评估中得分最高，即使在 medium effort 下也领先。
- **知识工作：** Hebbia 金融基准测试（高级推理）得分最高，在文档推理、图表解读、问题解决方面大幅提升。IMC 反馈 Fable 5 几乎全通过了交易分析评估（事实查询、概念推理、根因分析、期望值分析）。
- **视觉能力：** 新 SOTA。仅靠原始游戏截图就通关了 Pokémon FireRed（之前 Claude 模型需要复杂辅助 harness）。能从截图中重建 web app 源码。
- **记忆与长上下文：** 在 Slay the Spire 游戏中，持久化文件记忆对性能的提升是 Opus 4.8 的三倍，通关最后一幕的频率也是三倍。
- **药物设计：** Mythos 5 将药物设计流程加速约 10 倍。14 个蛋白质靶点中 9 个产出了强候选药物。
- **分子生物学假设：** Mythos 5 是 Anthropic 第一个能持续产出新颖科学假设的模型。盲测中被科学家 80% 时间偏好 Mythos 的假设而非 Opus 级别的假设。一个关于 E. coli 蛋白的新机制已被独立实验室验证。
- **基因组学研究：** Mythos 5 自主工作一周多，组装了 138 个物种的数百万个单细胞数据，设计并训练了自定义 ML 模型来识别跨物种的同功能细胞，性能优于 Science 期刊发表的模型，同时体积小 100 倍。

**安全护栏：** Fable 5 配备了新的安全分类器，针对网络安全和生物研究领域。由于优先安全，护栏调得偏保守，约 5% 的会话可能触发误报。Anthropic 表示会在发布后持续优化减少误报。

**对齐评估：** Mythos 5 的错位行为水平（包括欺骗、配合用户滥用等）较低，与 Opus 4.8 相当，Fable 5 也是如此。

**14 家企业早期反馈：** Cursor（CursorBench SOTA）、GitHub（长周期编码自主性和可靠性突破）、Stripe（月级工作压缩到天级）、Cognition（FrontierBench 最高分）、Hebbia（首个突破 90% 核心分析基准的模型）等均给出极高评价。

## Claude Managed Agents 新增定时任务与环境变量 Vaults【⭐⭐】
**来源：** Claude Blog
**链接：** https://claude.com/blog/whats-new-in-claude-managed-agents
**关键词：** Managed Agents, 定时部署, 环境变量, vaults, CLI认证, 浏览器能力, public beta

### 摘要

Anthropic 为 Claude Managed Agents 平台发布两个新功能，均已进入 public beta。

**1. 定时部署（Scheduled Deployments）**

Agent 现在可以配置 cron 定时任务，无需自行搭建调度基础设施。每个调度触发时自动启动新会话执行任务，支持暂停/恢复/归档。

客户案例：
- **Rakuten**：按周/月自动分析电子表格数据生成报告和幻灯片，监控生产日志和指标
- **Actively AI**：为销售团队提供跨账户 Agentic 搜索，定时刷新答案，替代了团队此前自建的调度层
- **Ando**：Agent 自动监控招聘和销售流程，跟进待办事项，发送会议提醒

**2. 环境变量 Vaults（支持 CLI 认证）**

Vaults 现在支持环境变量，CLI 工具可以通过注入的变量发起认证请求。安全模型：Agent 沙箱中只持有占位符，真实密钥在网关层挂载，仅在请求你允许的域名时附加。Agent 永远不会看到原始密钥。

支持的 CLI 包括 Browserbase、KERNEL、Notion、Ramp、Sentry。其中 **Browserbase 和 KERNEL 首次为 Managed Agents 引入浏览器能力**——Agent 可以导航和操作网页。

客户案例：
- **Notion**：用 env vars in vaults 安全推送 Notion CLI，在 MCP 工具基础上增加文件上传能力，API token 从不暴露给模型
- **Browserbase**：通过 vaults 认证的 browse CLI 为 Agent 提供浏览器技能目录，定时部署定期校验目录准确性
- **KERNEL**：Agent 直连数据库追踪使用量和客户对话，实时标记用量异常
- **Milana**：AI 产品工程师通过 vaults 安全连接客户代码库，自动查找修复 bug，大规模数据分析速度大幅提升

**评价：** 这两个功能本质上在给 Managed Agents 补齐「自主运行」和「安全集成」两块短板，让 Agent 从需要手动触发+受限工具，进化到定时自动执行+安全访问外部系统。

## obra/superpowers：Agent 技能框架与软件开发方法论【⭐⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/obra/superpowers
**关键词：** agent skills, TDD, subagent-driven-development, 223K stars, Claude Code, Codex, Cursor

### 摘要

obra/superpowers 今天突然爆火，冲到 22.3 万星，成了 GitHub 今日最热项目。它的作者 Jesse Vincent（obra）是前 Stripe/VMware 工程师。

核心思路：给 coding agent 注入一套「方法论」而不只是工具。当 agent 看到你要写代码时，它不会直接写，而是先跟你确认需求 → 产出规格文档 → 制定实现计划 → 再派子 agent 执行任务。整个流程强制 TDD（红绿重构），每个任务 2-5 分钟完成，完成后自动 code review。

**工作流链条：** brainstorming（需求对齐）→ using-git-worktrees（隔离工作区）→ writing-plans（拆分任务）→ subagent-driven-development（子 agent 执行）→ test-driven-development（强制 TDD）→ requesting-code-review（自动 review）→ finishing-a-development-branch（合并/PR）。

支持 Claude Code、Codex CLI、Codex App、Factory Droid、Gemini CLI、OpenCode、Cursor、GitHub Copilot CLI 共 8 个平台。通过各平台的 plugin marketplace 安装。

这个项目的爆火时机很有意思：今天 Claude Fable 5 发布、Managed Agents 支持定时任务，同时 Google 也开源了 agent skills 仓库——「agent skills」这个范式正在从概念走向基础设施。

## ruvnet/RuView：WiFi 信号穿墙感知系统【⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/ruvnet/RuView
**关键词：** WiFi sensing, CSI, ESP32, DensePose, vital signs, edge AI, Home Assistant

### 摘要

ruvnet/RuView（72K stars）把普通 WiFi 路由器变成了「穿墙雷达」，利用 ESP32 传感器（$9/节点）采集 WiFi 信号的 Channel State Information（CSI），用脉冲神经网络在本地做实时推断。

能感知什么：房间内人员存在和计数（穿墙）、呼吸频率（6-30 BPM）和心率（40-120 BPM）无接触检测、17 个关键点的人体姿态估计（WiFi DensePose）、活动识别（走路/坐下/手势/跌倒）、睡眠质量和呼吸暂停筛查。

技术亮点：姿态估计模型 4-bit 量化后仅 8KB，在树莓派上跑微秒级推理；自研 Rust 实现 CSI 处理管线，1463 个测试通过；支持 Home Assistant、Apple Home、Google Home、Alexa 四大智能家居生态；完全边缘运行，无需摄像头、云端、用户佩戴设备。项目基于 MIT 协议，配套 Hugging Face 模型。

## activeloopai/hivemind：Agent 共享记忆引擎【⭐⭐】

**链接：** https://github.com/activeloopai/hivemind
**关键词：** agent memory, shared brain, Deeplake, Claude Code, OpenClaw, Y Combinator

### 摘要

activeloopai/hivemind（616 stars，Y Combinator 投资）是 Deeplake 公司推出的 agent 共享记忆引擎。核心卖点：「周一某个工程师的 agent 搞定了 tricky migration，周二全团队的 agent 都能执行这个模式。」

工作机制：捕获每个 session 的 prompts/工具调用/响应 → 挖掘重复模式 → 自动生成可复用的 SKILL.md → 混合检索（语义+BM25）→ 通过虚拟文件系统 hook 所有平台 agent。支持 Claude Code、OpenClaw、Codex、Cursor、Hermes、pi。

Benchmark 数据（LoCoMo 测试）：成本降低 25%（$8.94→$6.65/100 QA）、Token 消耗减少 1.7 倍、对话轮数减少 31%。支持 BYOC 存储。与 OpenClaw 的 memory-core 插件共存运行。
