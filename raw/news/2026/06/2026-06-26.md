### GLM-5.2 发布：从 Vibe Coding 到 Agentic Engineering【⭐⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/zai-org/GLM-5
**关键词：** GLM-5.2、长时域任务、1M上下文、744B参数、智谱

#### 摘要

智谱发布 GLM-5 系列最新旗舰模型 GLM-5.2，标志着从"Vibe Coding"到"Agentic Engineering"的跨越。整个 GLM-5 系列从 GLM-4.5 的 355B 参数（32B active）扩展到 744B 参数（40B active），预训练数据从 23T 提升到 28.5T token。

**GLM-5.2 核心升级：**
- **1M token 稳定上下文**：首次实现百万级 token 上下文的稳定长时域工作能力
- **强化编码能力**：Terminal-Bench 2.1 达到 81.0（vs GLM-5.1 的 62.0），SWE-bench Pro 达到 62.1，开源最强，逼近 Claude Opus 4.8（85.0）
- **IndexShare 架构创新**：每四层稀疏注意力共享一个索引器，1M 上下文下每 token FLOPs 降低 2.9×
- **MTP 推测解码优化**：接受长度提升最多 20%

**家族谱系：**
- GLM-5：基础版本，引入 DeepSeek Sparse Attention 降低部署成本
- GLM-5.1：Agentic Engineering，在长时间任务中可持续优化数百轮、数千次 tool call
- GLM-5.2：长时域任务旗舰，1M 上下文 + 最强编码

RL 训练方面，团队开发了 [slime](https://github.com/THUDM/slime) 异步 RL 基础设施，大幅提升训练吞吐和效率。Vending Bench 2（模拟自动售货机一年经营）中 GLM-5 以 $4,432 余额排名开源第一。

模型已上架 HuggingFace 和 ModelScope，支持 SGLang、vLLM、Transformers、KTransformers 等框架部署。

### Anthropic 发布 Claude Code 官方插件目录【⭐⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/anthropics/claude-plugins-official
**关键词：** Claude Code、插件市场、Anthropic、skill-bundle

#### 摘要

Anthropic 正式推出 Claude Code 官方插件目录（claude-plugins-official），作为 Claude Code 默认内置的插件市场。该仓库包含两类插件：

- `/plugins`：Anthropic 内部开发和维护的插件
- `/external_plugins`：第三方合作伙伴及社区插件

**安装方式**：`/plugin install {plugin-name}@claude-plugins-official` 或通过 `/plugin > Discover` 浏览安装。

**关键设计：**
- 支持 skill-bundle 模式：不要求 `.claude-plugin/plugin.json`，可通过 `strict: false` + 显式 `skills` 数组直接声明技能包
- AWS 已率先入驻，提供 `aws-core`、`aws-agents`、`aws-data-analytics`、`aws-agents-for-devsecops` 四个插件
- 外部提交需通过 [clau.de/plugin-directory-submission](https://clau.de/plugin-directory-submission) 表单，需满足质量和安全标准

这是 Claude Code 生态成熟的关键一步——从分散的技能/插件分发转向中心化、可审查的官方市场。

### AWS 发布 Agent Toolkit for AWS【⭐⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/aws/agent-toolkit-for-aws
**关键词：** AWS、MCP Server、Claude Code插件、AI Agent、DevOps

#### 摘要

AWS 正式推出 Agent Toolkit for AWS，让 AI 编码代理（Claude Code、Codex、Cursor、Kiro 等）直接操作 AWS 服务。核心组件：

**四个 Claude Code 插件：**
- `aws-core`：覆盖服务选择、CDK/CloudFormation、Serverless、容器、存储、可观测性、计费、SDK、部署
- `aws-agents`：在 Amazon Bedrock 和 AgentCore 上构建 AI Agent
- `aws-data-analytics`：数据湖、分析和 ETL（S3 Tables、Glue、Athena）
- `aws-agents-for-devsecops`：安全事件调查、代码审查、UAT、漏洞扫描、渗透测试（集成 AWS DevOps Agent 和 Security Agent）

**AWS MCP Server** 提供：
- 300+ AWS 服务 API 覆盖
- 沙箱化 Python 脚本执行
- 实时文档搜索（无需认证）
- 企业管控：CloudWatch、IAM 上下文键、CloudTrail 审计

这是大厂中首个系统化地将 Agent 能力接入云平台的产品，AWS 通过 MCP + 插件体系让 AI 代理在云上具备了从开发到运维的完整能力链。

### 阿里开源 PageAgent：让网页拥有 GUI Agent【⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/alibaba/page-agent
**关键词：** 阿里、GUI Agent、网页自动化、JavaScript、npm包、自然语言操控

#### 摘要

阿里巴巴开源 PageAgent，一个运行在浏览器页面内的 JavaScript GUI Agent。用自然语言操控网页界面，无需浏览器扩展、无需 Python、无需无头浏览器。

**核心特性：**
- 纯前端 JS：一行 `<script>` 即可集成到任何网页
- 基于文本 DOM 操作：不需要截图或多模态 LLM
- 支持 BYO LLM（默认集成通义千问）
- 可选的 Chrome 扩展实现多页面任务
- Beta 版 MCP Server：允许外部 Agent 客户端操控浏览器

**应用场景：**
- SaaS AI Copilot：几行代码给产品增加 AI 助手
- 智能表单填写：20 步操作变一句话
- 无障碍访问：自然语言 + 语音指令
- 多页面 Agent + MCP 集成

NPM 包名 `page-agent`（v1.10.0），基于 MIT 协议，DOM 处理借鉴了 `browser-use` 项目。已在 HN 引起讨论。

### SimpleX Chat：无用户标识的私人通讯【⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/simplex-chat/simplex-chat
**关键词：** SimpleX、隐私通讯、无标识符、端到端加密

#### 摘要

SimpleX 是首个完全不使用任何用户标识符（无手机号、无邮箱、无用户名）的通讯网络，100% 隐私优先设计。已通过 Trail of Bits 安全审计，被 Privacy Guides 和 Whonix 推荐。支持 iOS、Android 和桌面端。

核心设计理念：不依赖用户 ID，而是通过单向连接的队列来传递消息，从协议层面消除元数据泄露。与 Signal、Telegram 等传统加密通讯工具的根本区别在于——没有可以被追踪的用户身份。

### comma.ai openpilot：开源自动驾驶操作系统【⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/commaai/openpilot
**关键词：** comma.ai、openpilot、自动驾驶、机器人操作系统、ADAS

#### 摘要

openpilot 是 comma.ai 开源的机器人操作系统（MIT 协议），目前用于升级 300+ 款车型的驾驶辅助系统。运行在 comma four 硬件设备上，通过车辆线束连接原车 CAN 总线，实现车道保持、自适应巡航等 L2 级辅助驾驶功能。

项目包含完整的感知-规划-控制管线：端到端模型从摄像头输入直接输出转向/油门/刹车指令，代码库涵盖传感器驱动、车辆接口、模型训练和仿真。社区活跃（Discord 47000+ 成员），支持多分支发布（release-mici 稳定版 / master 开发版），一键安装：`bash <(curl -fsSL openpilot.comma.ai)`。
