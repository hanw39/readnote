## LMCache/LMCache【⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/LMCache/LMCache
**关键词：** LLM KV Cache 加速、vLLM 集成、9K Stars

### 摘要

"用最快的 KV Cache 层给你的 LLM 加速。"LMCache 是专门优化 LLM 推理中 KV Cache 层的工具，支持 CUDA 和 ROCm（AMD GPU），能直接集成 vLLM。9K Stars。

KV Cache 是大模型推理的核心瓶颈之一——每次推理都要重新计算 attention 的 key/value，缓存能大幅减少重复计算。LMCache 的创新在于把缓存层做成了通用组件，不依赖特定推理框架。支持 AMD GPU 也增加了灵活性（很多推理优化工具只支持 NVIDIA）。

## Meet the Winners of Built with Opus 4.7 Claude Code Hackathon【⭐⭐】
**来源：** Claude Blog
**链接：** https://claude.com/blog/meet-the-winners-of-built-with-opus-4-7-claude-code-hackathon
**关键词：** Claude Code Hackathon, Opus 4.7, Agent 应用, 医疗教育, 电子维修, CS教育, 预测性维护

### 摘要

Anthropic 公布了"Built with Opus 4.7"黑客松获奖项目，6 个优胜项目展现了 Claude Code 在垂直领域的落地广度——从伊斯坦布尔医学院到智利乡村木工，从法国维修铺到工厂车间。

**一等奖 Medkit（Bedirhan Keskin）**：伊斯坦布尔医生转软件工程师，用 Claude Managed Agents 构建了面向住院医的游戏化临床模拟训练工具。学生在虚拟急诊室中问诊、开化验单、读影像、诊断、开处方，最后由 agentic grader 按临床指南自动评分。4 个独立 Claude Code session 并行开发（语音引擎、内容生成、3D 游戏层、核心应用），全程语音操作。已有 3 所医学院和 1 家药企即将试点。核心理念："Claude 不只是代码生成器，更是思维搭档。"

**二等奖 Wrench Board（Alexis Chapellier）**：法国维修铺出身的自学开发者，做了电子维修诊断工具——上传电路原理图和板视图，agent 生成统一电气图并推理，精确定位焊盘位置，读取测量值后不断更新诊断假设。调试时用 5-6 个 agent 并行跑 benchmark，全程用 Superpowers skills 框架做结构化头脑风暴。"Claude Code 放大任何有想法和耐力的人，无论起点如何。"

**三等奖 Maieutic（Paula Vásquez-Henríquez）**：智利大学 CS 教师，针对"学生用 AI 生成代码但完全不懂代码"的危机，做了一个反 Autocomplete 的 IDE——必须先写自然语言规格说明才能编码，AI 聊天栏用反问代替直接给答案，核心功能 Intent-Diff Review 自动对比规格说明和最终代码的差异。教师端有实时 dashboard 显示每个学生的认知摘要。休斯顿大学已联系合作论文。

**最具创意奖 Virtual Puppet Theater**：浏览器端交互木偶剧，摄像头捕捉动作 + AI 伙伴木偶对话 + 语音指令生成 3D 场景。技术栈：Bun + Three.js + MediaPipe + Claude Opus 4.7 空间推理。纯为好玩，没产品计划。

**"Keep Thinking"奖 MaestrIA（Benjamin Torralbo）**：智利 20 岁青年零编程经验，用 Claude Code 做了家居维修诊断工具。核心是访谈木匠大师父亲后提炼的 17 条诊断规则 + 7 种本地木材 + 19 个基准价格，单个 JSON 文件把准确率从 74% 提到 81%。拍照描述问题 → Claude 实时推理画标注框 → 生成诊断 → 匹配当地工匠 → 自动草拟 WhatsApp 消息。

**最佳 Managed Agents 应用奖 ARIA**：工厂预测性维护系统。上传设备手册 PDF + 4 个校准问题 → 15 分钟完成产线建模 → 5 个 agent 持续监控 → 自动生成工单。"没有 Managed Agents，我们需要花一周搭基础设施而不是做产品——这就是 5 天和 5 周的差距。"

**两点趋势信号：** (1) Claude Code 已覆盖从需求梳理到评估验证的完整产品构建流程，不只是写代码工具；(2) "先规划再编码"成为共识方法论——Maieutic 创始人花两天写规格说明才写代码，ARIA 团队花一整天做 GitHub Project 规划。
