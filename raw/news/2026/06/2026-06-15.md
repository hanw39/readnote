## Panniantong/Agent-Reach【⭐⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/Panniantong/Agent-Reach
**关键词：** Agent 互联网搜索、零 API 费用、多平台适配器、29,302星

### 摘要

Agent-Reach 的核心定位是"给 AI Agent 一双看遍互联网的眼睛"。一个 Python CLI 工具，让 AI Agent 直接读取和搜索 Twitter、Reddit、YouTube、GitHub、Bilibili、小红书六大平台，**零 API 费用**。

2.9 万星的增长速度非常惊人。这个项目解决了一个根本矛盾：AI Agent 需要从互联网获取信息，但每个平台都有独立的付费 API，集成成本极高。Agent-Reach 用网页抓取的方式绕过了 API 墙，一个命令行搞定所有平台。

**与同类对比：**
- `mvanhorn/last30days-skill`（4.2万星）也是跨平台信息聚合，但它是 Claude Code 的 Skill，依赖 Claude 运行时
- Agent-Reach 是一个独立的 CLI 工具，可以被任何 Agent（Claude Code、Cursor、自定义 Agent）调用
- Agent-Reach 的亮点是**零 API 费用**，这在中国开发者社区（B站、小红书是重点）尤其有吸引力

**战略意义：** Agent 的基础设施正在从"模型层"下沉到"数据接入层"。Agent 需要数据源，而 Agent-Reach 做的就是 Agent 时代的"网络 IO 层"——让 Agent 像浏览器一样自由访问互联网。

## trycua/cua【⭐⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/trycua/cua
**关键词：** Computer-Use Agent 基础设施、桌面自动化、跨平台沙箱、18,000星

### 摘要

CUA（Computer-Use Agents）的开源基础设施。提供沙箱（Sandboxes）、SDK 和基准测试，用于训练和评估能控制完整桌面环境（macOS、Linux、Windows）的 AI Agent。

1.8 万星，用 Swift/Virtualization Framework 实现 macOS 支持，是 Computer-Use 方向最全面的开源项目之一。

**技术栈亮点：**
- 三平台沙箱：macOS 用 Virtualization.framework，Linux 用容器，Windows 用 Windows Sandbox
- 不只是"让 AI 看屏幕"——提供完整的训练和评估流程
- HTML 作为主语言（可能意味着 Web UI/文档驱动）

**与 Anthropic Computer Use 的关系：** Anthropic 定义了 Computer-Use 的概念，但需要 Claude API 调用。trycua/cua 是开源的对等实现——你可以在本地跑，可以训练自己的模型，可以做评估。这是 Computer-Use 从"封闭能力"走向"开放基础设施"的关键一步。

**对比 `msitarzewski/agency-agents`（11.3万星）：** agency-agents 是 Agent 角色定义框架，cua 是 Agent 操作系统的执行层。两者互补——一个定义"谁是 Agent"，一个定义"Agent 能操作什么"。

## Raphire/Win11Debloat【⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/Raphire/Win11Debloat
**关键词：** Windows 优化、去臃肿、PowerShell、47,707星

### 摘要

一个轻量 PowerShell 脚本，专门用来给 Windows 10/11 "瘦身"——移除预装应用、禁用遥测、清理臃肿功能。4.7 万星，纯 PowerShell 实现，不需要安装任何第三方依赖。

**为什么火：** Windows 11 的预装软件和遥测越来越激进，用户对"控制自己的系统"的需求在增长。Win11Debloat 简单到"下载脚本 → 右键运行 → 选择要清理的东西 → 搞定"，零学习成本。

**对比 `itsfatduck/optimizerDuck`（3478星）：** 后者是 C# GUI 工具，功能更丰富但门槛更高。Win11Debloat 胜在轻量和透明——PowerShell 脚本意味着用户可以逐行审计它在做什么。
