## Dear ImGui v1.92.9 发布【⭐⭐】

**来源：** Github Trending Daily
**链接：** https://github.com/ocornut/imgui
**关键词：** Dear ImGui, GUI框架, C++, 游戏开发, Metal 4, 版本发布

### 摘要

Dear ImGui 发布 v1.92.9，这个拥有 75,000+ stars 的 C++ 轻量级 GUI 库带来多项重要更新：

**Breaking Changes：** 默认禁用 scalar 类控件的 LiveEdit —— 之前 DragFloat/SliderInt 等输入时会逐字符写入中间值（输"123"会依次写入 1、12、123），现在改为失焦/回车后才写入，与直觉更一致。文本输入保持原有行为不变。

**新增 Metal 4 后端：** 支持 Apple 最新的 Metal 4 API，包含 multi-viewport 支持，同时有对应的示例项目。

**Table 列匹配重写：** 当 Table 列带 label 时，底层用标识符匹配列数据和 .ini 设置，从此增删列不再丢失状态。新增右键菜单中的"Reset"子菜单。

**样式增强：** 新增 MenuItemRounding 和 SelectableRounding 圆角控制；InputText 光标粗细可通过 style.InputTextCursorSize 配置。

**设置清理机制：** 可记录设置最后使用日期（YYYYMMDD），支持按时间自动丢弃旧设置（ConfigIniSettingsAutoDiscardMonths），Metrics 窗口新增设置清理工具。

**其他：** ColorEdit 标志可通过 io.ConfigColorEditFlags 全局配置；ColorPicker 新增 PickerNoRotate 选项；修复了大量 Android/Win32/OpenGL 的兼容性问题。

这次更新对游戏开发、工具链和桌面应用开发者非常实用，特别是 LiveEdit 行为变更和 Table 列状态管理重构。

## AG KIT — Google Antigravity 的 Agent 工程套件【⭐⭐⭐】

**来源：** Github Trending Daily
**链接：** https://github.com/vudovn/ag-kit
**关键词：** Agent 工程, Google Antigravity, 规则系统, MCP, 技能管理, TypeScript

### 摘要

vudovn/ag-kit 是一个面向 Google Antigravity 平台的 Agent 工程套件，发布即斩获 7838 stars。它提供了完整的 `.agents/` 工作区契约，包含：

- **规则与技能发现：** `.agents/rules/`、`.agents/skills/`、`.agents/workflows/` 三层结构
- **专家路由：** 20 个角色定义 + 智能路由技能
- **持久化上下文：** `.agents/memory/` 目录 + 上下文压缩指引
- **编排能力：** `/coordinate`、`/orchestrate` 指令 + Antigravity 原生 `/agents`、`/tasks`
- **MCP 支持：** 工作区配置 + 显式备份感知同步助手
- **安全钩子：** 原生 `PreToolUse` 门控，拦截根文件系统删除、磁盘格式化等危险操作，但不妨碍正常的 `dist/` 或 `node_modules/` 清理
- **验证工具链：** CI 检查、Antigravity Doctor、回归测试、SHA-256 内容清单

安装方式：`npx @vudovn/ag-kit init` 或全局安装 `npm install -g @vudovn/ag-kit`。要求 Node.js 22+、Python 3.10+ 和受信任的 Google Antigravity 工作区。

这标志着 Agent 工程正在走向标准化、组件化的方向。AG KIT 本质上是一套 Agent 工程最佳实践的参考实现，类似于前端领域的 create-react-app 之于 React 项目的意义。其生产级特性包括安全钩子、插件打包和完整的验证流水线，显示出这不是一个玩具项目。当前仍以 Antigravity 为唯一生产运行时，但 Markdown 组件理论上可被其他工具读取。

## Google 开源 Tunix：JAX 原生的 Agentic RL 训练框架【⭐⭐⭐】

**来源：** Google AI（Google Developers Blog）
**链接：** https://developers.googleblog.com/scaling-agentic-rl-high-throughput-agentic-training-with-tunix/
**关键词：** Agentic RL, JAX, TPU, 强化学习, LLM 对齐, 开源, 异步训练

### 摘要

Google 正式开源 Tunix，这是一个 JAX 原生的 agentic RL 后训练库，专门解决 LLM Agent 多轮工具调用训练中的核心瓶颈——TPU 空闲等待。

**核心问题：** 传统 RL 训练中，当 Agent 暂停执行代码、查询数据库或等待网络搜索时，昂贵的 TPU 加速器完全闲置。Agent 交互的同步等待（environment step）造成了严重的执行气泡和拖尾效应（straggler effect）。

**Tunix 的三个关键设计：**

1. **异步解耦式 Rollout：** 基于 Python asyncio 的高并发 RolloutOrchestrator，管理大量并发的 agent-environment 交互。当一个 Agent 等待工具执行时，推理引擎立即切换到其他活跃 trajectory。原生集成 vLLM-TPU 和 SGLang-Jax 推理引擎，确保推理、工具执行、奖励计算完全重叠。

2. **生产者-消费者流水线：** 将 rollout 和训练解耦为持续的生产者-消费者架构。异步 rollout 编排器持续产出完成的 trajectory 到高吞吐队列，AgenticRLLearner 动态分组后直接喂给训练器。对于 GRPO 这类需要多条推理路径计算 group advantage 的算法，Tunix 在飞行中完成动态分组。

3. **可组合的 Agent/Environment 抽象：** 通过清晰的 API 边界，Agent 和 Environment 完全解耦。预置了 ModelAgent、ToolAgent 和 TaskEnvironment、ToolEnvironment。只需继承 ConversationAgentBase 或 BaseTaskEnv 即可接入任何自定义 Agent/环境。接入 Gymnasium 等开源环境只需实现 `_initial_observation`、`_step_impl`、`close` 三个方法。SWE-bench、WebArena 等标准评测环境均可在几分钟内接入。

**轻量级领域 Profiling：** 传统的 XProf 对长时间 agentic training 开销过高。Tunix 内置持续运行的轻量级埋点，围绕 RL 专属指标（rollout 阶段耗时、训练阶段、权重同步等），与 Perfetto trace 结合后能精确定位 TPU 饥饿时间点、验证流水线对齐状态、动态调优并发参数。

**生态对比：**
- vs OpenRLHF/veRL：后者基于 Ray + vLLM + PyTorch，Tunix 是 JAX/TPU 原生方案，利用 XLA 编译器优化和 Pathways 多主机分布式训练
- vs HuggingFace TRL：TRL 适合单轮 SFT/RLHF，多轮异步循环需要大量自定义胶水代码，Tunix 将多轮工具调用作为一等公民
- vs Ray RLlib：RLlib 是通用 RL 框架，Tunix 是 LLM-first 设计，将高性能 RL 直接融入 LLM 推理基础设施

**开源地址：** github.com/google/tunix，包含 SWE coding agent、数学推理、游戏 agent 等 recipe 示例。

这是 Google 对 Agentic RL 训练基础设施的一次重要开源贡献。Tunix 的定位清晰——不在 PyTorch 生态重复造轮子，而是将 agentic RL 训练能力带给 JAX/TPU 用户。对于使用 Google Cloud TPU 且有 Agent 训练需求的团队，这是目前最直接的 native 解决方案。
