## Anthropic 推出 Economic Index Connector：让 Claude 直接回答经济指数数据【⭐⭐⭐】
**来源：** Anthropic News
**链接：** https://www.anthropic.com/news/anthropic-economic-index-connector
**关键词：** Anthropic Economic Index, Claude Connector, AI经济影响, 数据可访问性

### 摘要
Anthropic 发布了 Anthropic Economic Index Connector，集成到 Claude 中，让用户可以直接对 Claude 提问关于 AI 经济影响的数据问题。Economic Index 衡量的是 AI 在经济中的实际使用情况（基于 Claude 使用数据而非整个劳动力市场）。用户可以在 claude.ai 的 connectors 目录中找到并启用该连接器，支持所有 Claude 模型，无需安装。

典型查询场景包括："哪些职业使用 AI 最多？""科罗拉多州的人们最常见的 Claude 使用方式是什么？""教师在哪些任务中使用 Claude？""AI 自动化了哪些任务，过去一年有什么变化？"Claude 会在回答中指明数据来源和局限性。完整数据集仍然在 Anthropic 网站上免费提供。

这项功能降低了 Anhropic 经济数据的使用门槛——此前这些数据主要被研究人员、记者和政策制定者使用，现在普通用户也能自由探索。

**点评：** 这是 Anthropic 将研究数据产品化的一个有趣案例。把原本需要下载 CSV/API 的专业数据变成了自然语言问答，降低了使用门槛。不过这个功能本质上是对现有数据的 Chat UI，没有新增数据集，更像是 Anthropic 在普及自己的经济研究叙事。

## Anthropic 公布 2 亿美元经济未来研究基金议程【⭐⭐⭐】
**来源：** Anthropic News
**链接：** https://www.anthropic.com/news/economic-futures-research-fund-agenda
**关键词：** Economic Futures Research Fund, $200M, AI经济冲击, 政策研究, 劳动力市场

### 摘要
Anthropic 公布了其 Economic Futures Research Fund 的详细研究议程，承诺投入 2 亿美元支持外部研究，旨在为社会应对 AI 经济冲击做好准备。该基金是之前 Economic Futures 项目的重大升级，从多笔小额资助转向大额、高影响力的研究项目。

**五大研究优先方向：**
1. **塑造 AI 对工作场所工人的影响** —— 通过企业/团队级别的随机对照试验（RCT），研究不同 AI 集成设计（包括工人参与 vs 自上而下）对生产力和收益分配的影响
2. **帮助人们应对 AI 驱动的职业转型** —— 评估技能再培训、就业匹配、资格证书改革等项目，包括 AI 赋能的匹配和认证模型
3. **现代化收入支持应对 AI 导致的失业** —— 研究与再培训、搬迁援助绑定的收入支持方案
4. **在 AI 增长红利到来前建立工人权益** —— 在 disruption 发生前让工人获得 AI 增长的收益
5. **公共投资的新证据** —— 生成关于哪些公共投资能最有效缓解 AI 冲击的实证数据

**资助规模：** 单个项目 500 万-3000 万美元，不接受低于 100 万美元的申请。面向大学、独立研究所、非营利机构，鼓励在关键节点公开分享研究发现。全球性基金，但研究方向偏美国视角（因 Anthropic 总部在旧金山且 Claude 在美使用最多）。

**点评：** 这笔基金的规模和定位都很有野心——不是做渐进式学术研究，而是鼓励大规模试点和大胆假设。500万-3000万/项目的预算意味着 Anthropic 不是在"撒钱"，而是真的想推动可落地的政策实验。但研究偏美国视角是个短板，AI 对发展中国家的劳动力冲击可能更剧烈。另外，一家 AI 公司资助"如何应对 AI 冲击"的研究，本身就是耐人寻味的信号。

## Outtake 基于 Claude 构建自主网络调查员【⭐⭐】
**来源：** Claude Blog
**链接：** https://claude.com/blog/how-outtake-built-a-cyber-investigator-on-claude
**关键词：** Outtake, cybersecurity, Claude Code, Agent SDK, 自主Agent, 网络安全

### 摘要
这是一篇 "How startups build with Claude" 系列文章，介绍了 AI 网络安全平台 Outtake 如何使用 Claude Code 和 Agent SDK 构建 Recon Agent——一个自主网络调查员。

**公司背景：** Outtake 成立于 2023 年，CEO Alex Dhillon 曾在 Palantir 的 moonshot 团队工作。公司 ARR 年增长 6 倍，客户群年增长超 10 倍，2025 年扫描了 2000 万+ 潜在网络攻击。客户包括顶尖 AI 实验室、主要对冲基金和美联邦机构。

**核心能力：** Recon Agent 统一了"数字信任攻击链"的完整防御——从公开数据武器化 → 仿冒页面/身份诱饵 → 内部系统渗透。传统安全工具只覆盖其中一环（威胁情报/品牌保护/终端安全），Outtake 的优势在于 Agent 可以跨整个链条进行调查。

Agent 的具体工作流：从仿冒事件出发，收集证据 → 追踪关联基础设施（如假冒客服 Telegram 账号）→ 构建对抗网络图谱 → 生成报告（威胁行为者画像 + 攻击时间线）。Agent 甚至可以直接与恶意登录页交互，追踪被盗凭证流向。

**性能数据：** Agent 会话中位数 16 分钟，常规运行 1 小时+，最长记录 2 小时。全程自主运行，支持代码读写和执行。

**点评：** 这篇文章的核心观点值得玩味——"agentic offense needs agentic defense"。AI 降低了攻击成本，传统安全工具的碎片化防御越来越不够用，Agent 能跨域调查是差异化优势。不过这篇毕竟是官方合作案例，读到后面更像 Claude Code 推广文。

## Claude Code 验证循环：用 Skills 自动化代码检查【⭐⭐】
**来源：** Claude Blog
**链接：** https://claude.com/blog/building-verification-loops-in-claude-code-with-skills
**关键词：** Claude Code, verification loops, skills, agentic coding, 自动化验证

### 摘要
Anthropic 官方博客介绍了如何在 Claude Code 中将手动检查转化为自动验证循环（verification loops），让 Claude 自我检查并修复代码。

**核心概念：** Agentic coding 遵循 "收集上下文 → 执行操作 → 验证结果 → 循环" 的模式。验证环节通常是开发者手动做的——运行测试、检查 lint、确认页面渲染正常。这些步骤可以编码为 skill，让 Claude 自动迭代直到通过验证。

**内置验证能力：**
- `/verify` skill：构建、运行并观察应用变化
- 工具链集成：自动捕获 linter/compiler 错误和警告
- Code Review（研究预览版）：多 Agent 服务自动审查 PR
- GitHub Actions 集成：推送/PR 时自动运行验证 skill
- Spec 验证：基于 repo 中的 markdown spec 检查变更
- Rubrics + Managed Agents（beta）：用评分 Agent 验证结果，失败自动重试

**自定义验证 Loop 的方法：**
1. 记录你每次手动检查 Claude 代码时的重复步骤
2. 用 `/skill-creator` 插件让 Claude 采访你的工作流，自动生成 skill
3. 或者手写 markdown 放到 `.claude/skills/` 目录

实用建议：验证规则不一定非得是"软性的质量判断"，硬性规则如"拒绝任何删除列但没有回填步骤的 migration"同样适合编码为验证步骤。

**点评：** 这篇文章的价值在于系统化了验证循环的概念。大多数 Claude Code 用户其实已经在做类似的事（让 Claude 跑测试、修 lint），但把"你每次手动做的检查"显式化并编码为可复用的 skill 是一个很好的工程实践。本质上是把 implicit feedback loop 变成了 explicit verification pipeline。
