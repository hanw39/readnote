## Impeccable：AI 设计语言技能包【⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/pbakaus/impeccable
**关键词：** AI设计、前端设计系统、Claude Skill、设计检测器

### 摘要

pbakaus 发布的 AI 编码代理设计指导工具，上线不到一年已获 50k+ stars。Impeccable 在 Anthropic 的 frontend-design skill 基础上做了大幅扩展：

- **一套初始化流程**：`/impeccable init` 自动生成 PRODUCT.md 和 DESIGN.md，让后续命令能理解项目受众、品牌定位、色彩/字体/组件体系
- **23 个命令**：涵盖从 `craft`（完整从零构建）、`polish`（最终润色）、`audit`（技术质量检查）、`critique`（UX评审）到 `animate`、`delight`、`overdrive` 等细粒度操作
- **60 条确定性检测规则** + LLM 评审检查：CLI 和浏览器扩展运行确定性规则时无需 LLM、无需 API key
- **反模式清单**：明确禁止 AI 生成的常见设计套路——Inter 字体、紫蓝渐变、卡片套卡片、灰色文字放彩色背景等

定位很清晰：给 AI coding agent 一个共享的设计词汇表，让 AI 不再生成千篇一律的 SaaS 模板风界面。

## bitchat-android：去中心化蓝牙 Mesh 聊天【⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/permissionlesstech/bitchat-android
**关键词：** 去中心化通讯、蓝牙Mesh、端到端加密、P2P、IRC

### 摘要

bitchat iOS 版的 Android 移植，6.2k stars。核心卖点：**无需互联网、无需服务器、无需手机号**，纯蓝牙 Mesh 网络实现去中心化即时通讯。

技术亮点：
- X25519 密钥交换 + AES-256-GCM 端到端加密
- 蓝牙 LE 自动发现对等节点，支持多跳消息中继
- 频道制群聊，支持密码保护
- 离线消息缓存（Store & Forward），对等节点上线后自动投递
- IRC 风格命令（`/join`、`/msg`、`/who`），三击 Logo 紧急擦除所有数据
- Jetpack Compose + Material Design 3，终端美学

项目声明未经过外部安全审计，不建议用于敏感场景。但从概念验证角度看，Bluetooth Mesh 通讯的方向很有意思——停电断网场景、抗议/灾难应急通讯等都有应用潜力。

## Amnezia VPN Client：多协议翻墙客户端【⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/amnezia-vpn/amnezia-client
**关键词：** VPN、翻墙、OpenVPN、WireGuard、Shadowsocks、Cloak

### 摘要

Amnezia VPN 是一个桌面+移动端 VPN 客户端，13k stars，C++ 编写。支持多协议：OpenVPN、WireGuard、IKEv2、Shadowsocks、Cloak。项目标签明确写了 "gfw" 和 "cloak"，定位是针对深度包检测（DPI）的规避工具。

与 Shadowsocks/V2Ray 等代理工具不同，Amnezia 是一个完整的 VPN 客户端/服务端方案，更适合需要全设备流量加密的场景。

## Jenkins：经典 CI/CD 自动化服务器【⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/jenkinsci/jenkins
**关键词：** CI/CD、DevOps、Java、自动化构建

### 摘要

Jenkins 自动化服务器主仓库，25.6k stars，Java 编写。作为持续集成/持续交付领域的元老级工具，Jenkins 依然是企业级 DevOps 流水线的核心组件。支持 pipeline-as-code（Jenkinsfile）、海量插件生态、跨平台部署。

虽然近年来 GitHub Actions、GitLab CI 等云原生方案崛起，Jenkins 在自托管、高度定制化的 CI/CD 场景中仍不可替代。
