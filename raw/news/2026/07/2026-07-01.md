## Getting started with loops — Claude Code 官方定义 Agentic Loop【⭐⭐⭐】
**来源：** Claude Blog
**链接：** https://claude.com/blog/getting-started-with-loops
**关键词：** Claude Code, agentic loops, /goal, /loop, /schedule, 工作流设计

### 摘要

Anthropic Claude Code 团队发布了关于 agentic loop 的正式定义和实践指南，把最近热议的 "设计 loop 而不是写 prompt" 做了系统化阐述。

核心定义：**Agentic Loop = Agent 重复执行工作循环，直到满足停止条件。**

四种 Loop 类型：

1. **手动循环（Manual Loop）** — 每个 prompt 启动一轮。你发指令，Claude 读代码→改代码→测试→返回结果，你人工检查后再发下一轮。适用于短任务、非周期性工作。改进方式：把人工验证步骤编码成 SKILL.md。

2. **目标循环（/goal）** — 定义"完成"的标准，Claude 自动迭代直到目标达成或达到最大轮数。核心技巧：用确定性指标（如测试通过数、Lighthouse 分数）而非模糊描述。例：`/goal get the homepage Lighthouse score to 90 or above, stop after 5 tries`。每轮由 evaluator model 检查条件决定是否继续。

3. **时间循环（/loop 和 /schedule）** — 按时间间隔触发。`/loop 5m check my PR...` 在本地运行；`/schedule` 把循环搬到云端。适合周期性任务（如每天早上总结 Slack 消息）或对接外部系统（如监控 PR 评审和 CI 状态）。

4. **主动循环（Proactive Loops）** — 无人在回路，由事件或调度触发，每个子任务用 /goal 定义完成标准，整体 routine 持续运行直到手动关闭。适合 Bug 报告处理、Issue Triage、依赖升级等大规模重复性工作。

代码质量建议：干净的代码库是第一位的（Claude 会遵循已有模式）；引导 Claude review 自己的 PR 如同对同事一样；路由简单任务到小模型，只在需要判断时才用强模型。
