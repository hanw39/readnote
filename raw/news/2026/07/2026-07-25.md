## Claude Opus 5 发布：接近 Fable 5 前沿水平的「日常模型」【⭐⭐⭐】
**来源：** Anthropic News
**链接：** https://www.anthropic.com/news/claude-opus-5
**关键词：** Claude Opus 5、Frontier-Bench、Fable 5、编码基准测试、性价比

### 摘要

Anthropic 在 7 月 24 日正式发布 Claude Opus 5，定位为「接近 Fable 5 前沿智能、但价格只有一半」的日常使用模型。Opus 5 是 Claude Max 的默认模型，也是 Claude Pro 上最强的模型。

性能亮点：
- **Frontier-Bench v0.1**：Opus 5 超过所有其他模型，比 Opus 4.8 性能翻倍且每次任务成本更低
- **CursorBench 3.2**：在 max effort 下得分仅比 Fable 5 低 0.5%，但成本减半
- **ARC-AGI 3**（新问题求解评测）：得分是第二名的三倍
- **Zapier AutomationBench**：通过率约为第二名的 1.5 倍；即便最低 effort 下也能通过比任何其他模型更多的任务
- **OSWorld 2.0**（计算机使用基准）：在任何成本下都超越所有模型，用 Fable 5 三分之一的成本达到 Fable 5 最佳结果

在生命科学领域，Opus 5 在每个内部评测上都优于 Opus 4.8，有机化学（+10.2pp）和蛋白质功能预测（+7.7pp）提升最大。

代理能力（Agency）印象深刻：Frontier-Bench 中一项任务要求从机械零件图纸重建 3D 模型，Opus 5 自己写了一套计算机视觉管线提取几何信息并成功重建——没有其他模型能在 5 次尝试内完成。它还能排查真实开源包管理器的根因 bug（竞品只修复了表面症状就报 bug 已解决）。早期用户反馈一致强调其「稳定性」和「可靠性」——Lovable 的 Fabian Hedin 说 Opus 5 比 Opus 4.7 在困难任务上提升 22%，且方差远小于前代。

Opus 5 还支持更强的视觉输出（如空气动力学模拟可视化）。

## Project Pilot：AI 能操控无人机吗？—— Anthropic 前沿红队最新评估【⭐⭐⭐】
**来源：** Anthropic Research
**链接：** https://www.anthropic.com/research/project-pilot
**关键词：** 无人机、Drone-Bench、物理世界 AI、红队、双用途

### 摘要

Anthropic 与 Andon Labs 合作发布 Project Pilot——评估 AI 模型自主操控无人机执行定位追踪任务的能力，并发布新基准 Drone-Bench。这是 Anthropic「AI+物理世界」研究系列的新篇（继 Project Vend（经营小店）和 Project Fetch（机器狗取物）之后）。

核心任务：控制四旋翼无人机在室内办公环境中定位并跟踪一个指定人物。任务被分解为 5 个子任务：
1. **Reconstruct**：将办公室视频转为 3D 模型并生成 2D 障碍地图
2. **Localize**：将无人机当前画面匹配到 2D 地图上的位置
3. **Navigate**：在障碍地图上规划路径并飞行（实时调用 Localize 纠偏）
4. **Detect**：从参考照片构建人脸检测器，在实时画面中框出目标
5. **Follow**：用检测框控制无人机保持目标居中、距离稳定

Andon Labs 提供了人类+编码代理协作开发的基础算法作为基准线，模型需要达到或超过基准线才能算完成任务合格。

Anthropic 强调无人机的双重用途属性——既能用于搜索救援、农业增产，也能用于军事目标锁定——因此既有重要经济价值也带来新的风险面，需要技术开发者、公民社会和政府共同建立治理框架。

## Claude 模型选择指南：如何为你的场景选对模型【⭐⭐】
**来源：** Claude Blog
**链接：** https://claude.com/blog/claude-models-explained-choosing-the-best-model-for-your-use-case
**关键词：** 模型选择、Mythos/Fable/Opus/Sonnet/Haiku、Advisor 策略、effort level

### 摘要

Anthropic 发布官方模型选择指南，梳理当前 Claude 家族五个等级的定位：

- **Mythos / Fable**：同一底层模型的不同包装。Mythos 面向受信组织（Project Glasswing），处理双用途网络安全和生物任务；Fable 加装了额外安全护栏供公众使用。两者都需要有限数据保留。
- **Opus**：推理密集型企业任务的强力模型，在 GDPval-AA 和 Terminal-Bench 2.1 等基准中名列前茅。Opus 5 定位为「Fable 5 之下、性价比最优」。
- **Sonnet**：多功能日常模型，平衡性能、成本和速度，适合多代理编排中的高容量子代理。
- **Haiku**：最便宜最快的模型，适合延迟和成本敏感的高频工作负载。

关键核心理念：**不存在按行业分工——不是金融用这个、科学用那个**。差距在于模型能可靠承载的问题难度和成本。选择时应该问四个问题：任务多难？延迟需求？访问限制？单位经济？

特别推荐「Advisor 策略」：用更快更便宜的工作模型执行，仅在需要时调用更强模型来评估计划和检查质量。在 SWE-bench Pro 上，Sonnet 5 + Fable 5 advisor 能达到 Fable 5 分数的 90%，但成本只有 63%。

## Claude 5 代模型的上下文工程新规则：删掉 80% 系统提示词【⭐⭐】
**来源：** Claude Blog
**链接：** https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models
**关键词：** 上下文工程、系统提示词、渐进式披露、Claude Code、CLAUDE.md

### 摘要

Anthropic 技术团队成员 Thariq Shihipar 分享了对 Claude 5 代模型（Opus 5、Fable 5）做上下文工程的经验教训。核心发现：**他们从 Claude Code 的系统提示词中删掉了 80% 的内容，在编码评测中没有可测量的性能损失。**

六个「过去 vs 现在」的实践转变：

1. **给规则 → 用判断力**：老模型需要强约束（如「默认不写注释」），新模型写「代码应匹配周围代码的注释密度」就够了——用自然判断替代硬规则
2. **给示例 → 设计接口**：示例反而限制新模型的探索空间。更好的做法是通过参数设计来表达意图（如 Todo 工具的状态枚举就暗示了使用方式）
3. **全塞前面 → 渐进式披露**：把代码审查和验证逻辑移到独立 Skill 文件，按需加载。工具也支持「延迟加载」模式
4. **重复强调 → 简洁工具描述**：删除系统提示词中对工具的重复说明，把使用指导放在工具描述中
5. **CLAUDE.md 做记忆 → 自动记忆**：Claude 现在能自动保存相关记忆，不再需要用户手动 #
6. **简单 spec → 富引用**：不再只靠 Markdown 计划文件，Claude 可以引用 HTML artifacts、测试套件、代码库甚至 rubrics（通过动态工作流验证「品味」）

Anthropic 还推出了 `claude doctor` 命令，可以自动帮你精简 skills 和 CLAUDE.md 文件。文章强调：对于长 skills，应该拆分成多文件树、支持渐进式加载。

## 勇敢对话：高效领导力，从心开始【⭐⭐】
**来源：** McKinsey China
**链接：** https://www.mckinsey.com.cn/%e5%8b%87%e6%95%a2%e5%af%b9%e8%af%9d%ef%bc%9a%e9%ab%98%e6%95%88%e9%a2%86%e5%af%bc%e5%8a%9b%ef%bc%8c%e4%bb%8e%e5%bf%83%e5%bc%80%e5%a7%8b/
**关键词：** 领导力、勇敢对话、组织文化、心理安全、反馈文化

### 摘要

麦肯锡在新书《A CEO for All Seasons》的配套文章中，系统阐述了"勇敢对话"（courageous conversations）作为高效领导力核心支柱的理念。文章将领导者任期分为春夏秋冬四个阶段，每个阶段需要不同形式的勇气——春天坦诚面对未知，夏天清晰设标准+真实反馈，秋天挑战自满推动成长，冬天从容交接坦诚面对。

文章聚焦四种最常见的勇敢对话场景：

1. **鼓励提出异议**：视异议为责任而非不服从。心理安全感强的团队产生突破性想法的可能性是其他团队的2-3倍，示范行为改变的领导者让变革成功概率提升5.3倍。实操建议包括事前检讨（假设决策已失败倒推原因）、指定"首席挑战者"、设置"学习观察员"轮值岗。

2. **透明沟通开诚布公**：未解决的紧张关系使合作表现降低30%，而高度信任的团队长期表现优于其他团队50%。健康的组织文化让企业资本回报率高2.5倍、财务困境可能性低2.4倍。

3. **绩效面前说真话**：在绩效反馈中保持诚实而非回避，通过真诚反馈塑造高绩效文化。

4. **修复关系**：有勇气承认信任裂痕并主动修复。

文章强调勇气不只是危急时刻需要，而是日常实践——它是领导者内心信念与外在行动的源泉。

## permissionlesstech/bitchat：去中心化蓝牙 Mesh 聊天应用【⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/permissionlesstech/bitchat
**关键词：** 去中心化、蓝牙 Mesh、Nostr、P2P、隐私、iOS/macOS

### 摘要

bitchat 是一个去中心化的 P2P 消息应用，采用双传输架构：本地蓝牙 Mesh 网络实现离线通信，互联网端基于 Nostr 协议实现全球覆盖。无账号、无手机号、无中心服务器，定位为"side-groupchat"（侧频道群聊）。

**核心特性：**
- **双传输**：蓝牙 Mesh（本地离线）+ Nostr 协议（互联网全球）。智能路由会自动选择 Bluetooth 优先 → Nostr 回退
- **端到端加密**：蓝牙层使用 Noise Protocol，互联网层使用 NIP-17 礼品包装加密
- **基于地理位置的频道**：用 geohash 坐标创建不同精度的地理聊天室（街区/邻里/城市/省份/地区级别）
- **IRC 风格命令**：支持 `/slap`、`/msg`、`/who` 等熟悉界面
- **紧急擦除**：三击清空所有数据
- **性能优化**：LZ4 压缩、自适应电池模式
- **原生 iOS/macOS 双平台**（Swift/SwiftUI），已上架 App Store

技术架构上，蓝牙 Mesh 支持最多 7 跳中继，无需互联网即可工作——适用场景包括离线通信、抗议活动、灾难应急、偏远地区。Nostr 层通过 290+ 全球中继节点提供互联网覆盖。项目已开源至公共领域（public domain）。适合关注去中心化通信、隐私工具、离线优先应用的技术人员。
