## GLM-5.2：智谱最新旗舰，1M上下文+最强开源编程【⭐⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/zai-org/GLM-5
**关键词：** GLM-5.2, 1M Context, IndexShare, 开源模型, ZhipuAI

### 摘要
智谱发布了 GLM-5 系列模型，包含 GLM-5、GLM-5.1 和最新旗舰 GLM-5.2。GLM-5 基于 744B 参数（40B 激活），从 GLM-4.5 的 355B（32B 激活）大幅扩展，预训练数据从 23T 增至 28.5T tokens，集成 DeepSeek Sparse Attention 降低部署成本。

GLM-5.2 的核心突破：
- **1M Token 上下文**：首次在开源模型上稳定支持百万 token 长上下文
- **IndexShare 架构**：每四层稀疏注意力复用同一 indexer，1M 上下文下降低 2.9× per-token FLOPs
- **编程能力断层式提升**：Terminal-Bench 2.1 从 62.0→81.0，SWE-bench Pro 从 58.4→62.1，在所有开源模型中编程最强
- Terminal-Bench 2.1 得分 81.0，已接近 Claude Opus 4.8（85.0），超过 Gemini 3.1 Pro

GLM-5.1 专注 agentic engineering，在 SWE-Bench Pro、NL2Repo、Terminal-Bench 2.0 上均达 SOTA 水平。模型支持 SGLang、vLLM、Transformers、KTransformers、Unsloth 等多种部署框架。

- **Apache-2.0 协议**：完全开源商用

## Claude Voice Mode 升级：Opus/Sonnet 模型上车，支持多语言+工具调用【⭐⭐⭐】
**来源：** Claude Blog
**链接：** https://claude.com/blog/think-through-hard-problems-in-voice-mode
**关键词：** Claude, Voice Mode, Opus, Sonnet, 多语言, Connectors

### 摘要
Anthropic 宣布 Claude Voice Mode 重大升级（7月23日）。此前 Voice Mode 仅运行在 Haiku 模型上以保证速度，现在 Opus 和 Sonnet 模型正式上线语音模式——用户可在对话中随时切换模型。核心更新：
- **更深层的对话**：Claude 会追问、在用户思路基础上构建，而非直接给答案。Voice Mode 采用轮流对话（turn-taking），Claude 先听、再思考、再回应
- **工具调用**：语音对话可直接操作 Google Calendar（推迟会议）、Canva（生成一页纸文档）、总结当日邮件并起草回复。Claude 在使用已连接工具前会征求确认
- **11 种语言**：英语、法语、德语、印地语、印尼语、意大利语、日语、韩语、葡萄牙语（巴西）、西班牙语（拉美/西班牙）。语音模式下需主动告知或选择语言，不会自动检测
- **全计划可用**：Free 用户可用 Haiku + 1 个连接工具 + 所有语言；付费用户可用全部模型和所有连接工具

Voice Mode 在手机端体验最佳，同时支持桌面和 Web。语音对话计入常规使用额度。

- **30+ 数据库**：MySQL、PostgreSQL、Oracle、SQL Server、ClickHouse、MongoDB、Redis、SQLite、BigQuery 等，通过插件扩展
- **AI 助手**：接入自有模型，自然语言生成、解释、优化 SQL
- **完整 SQL 工作台**：编辑、补全、格式化、执行、历史记录
- **数据管理**：DDL/DML 操作、可视化数据编辑、ER 图
- **BI 能力**：仪表盘和图表、数据导入导出
- **CLI 工具**：开源的 Chat2DB-CLI 支持 MCP 协议

提供桌面客户端和 Docker 部署两种方式。定位类似 Navicat/DBeaver + AI，完全免费开源。
