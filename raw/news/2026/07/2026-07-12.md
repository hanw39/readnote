## 一文看懂ChatGPT、Codex、Work 的差别【⭐⭐⭐】

**来源：** 宝玉的博客
**链接：** https://baoyu.io/blog/chatgpt-work-codex-guide
**关键词：** OpenAI, ChatGPT, Work, Codex, Claude Cowork, 产品对比, Agent

### 摘要

宝玉写了一篇很实用的科普，把 OpenAI 最新产品线拆解得非常清楚。7月11日发的内容，正好赶上 ChatGPT Work 上线不久、Claude Cowork 也开始向网页和手机端扩展的时间点，所以还拉了 Claude 做横向对比。

先说 OpenAI 三个模式的核心定位：

- **Chat** — 回答问题。就是原来那个 ChatGPT，网页/手机/桌面都有，一切照旧。
- **Work** — 帮你干活。面向办公场景，能接 Slack、Gmail、Google Drive、Teams、Salesforce 等 60+ 个 plugins，目标是直接交付成品（文档、表格、幻灯片、网站），不是只给一段文字让你自己复制粘贴。
- **Codex** — 帮你写代码。面向开发者，读代码仓库、改代码、跑测试、提 PR。每周已有超过 500 万用户，其中 100 万+ 会拿它做编程以外的事。

**关键细节：**

- Work 支持定时任务（Scheduled Tasks），可设一次性、定时重复、事件触发和持续监控，能在后台跑。
- Work 和 Codex 共用同一套底层 Agent 能力，只是面向不同用户群。Work 本质上是把 Codex 非编程用途正式化。
- **额度不共享**：Chat 有独立消息限额，Work 和 Codex 共用另一个"智能体额度"池。Chat 聊再多不影响 Work/Codex，但 Work 和 Codex 互相挤占。
- 原来的独立 Codex App 已并入新版 ChatGPT 桌面端，三合一（Chat/Work/Codex），可切换。旧 ChatGPT 桌面端改名为 ChatGPT Classic。
- 4 月起改成按 Token 消耗计费，更强模型和 Fast 模式消耗更多额度。

**与 Claude Cowork 的对比（亮点）：**
1. **执行架构**：Cowork 用 Linux 虚拟机沙箱，ChatGPT Work 用 OS 原生隔离（macOS Seatbelt / Windows Sandbox）
2. **应用连接**：OpenAI 用 plugins 目录（60+ 连接器），Claude 用 MCP 协议（支持自建插件）
3. **跨设备同步**：Claude Cowork 同一会话可在桌面/网页/手机流转，OpenAI 的 Work 云端与桌面端目前还是割裂的（但"at launch"说明后续会补上）
4. **产品结构**：两家都在把 Chat、Work/Cowork、Code 三类模式塞进同一个桌面 App，趋势非常相似

**定价**：Work 不是独立付费产品，包含在 ChatGPT 订阅里，从免费版到企业版都可用，差别只是额度。

---

宝玉最后的总结很精辟：**Chat 给答案，Work 交成品，Codex 改代码。**关键在于搞清楚任务边界，而不是记住产品名。
