## An off switch for dual-use knowledge in AI models【⭐⭐⭐】
**来源：** Anthropic Research
**链接：** https://www.anthropic.com/research/off-switch-dual-use
**关键词：** GRAM、模块化预训练、双用途知识、可移除模块、AI安全

### 摘要
Anthropic 与 AE Studio 合作提出 GRAM（Gradient-Routed Auxiliary Modules）方法，核心思路是在 Transformer 每一层添加额外的神经元分组（模块），每个模块对应一类双用途知识（如病毒学、网络安全、核物理）。训练时，遇到双用途文本只更新对应模块，通用权重冻结不动。训练完成后可以像拔插头一样删除特定模块来移除对应能力，也可以保留给受信用户使用。

实验从三个层面验证：合成数据上表现与单独训练过滤模型几乎一致；在真实网页文本+代码+论文混合训练中，删除模块能有效移除对应能力且不损害通用性能；从 50M 到 5B 参数七个规模下 GRAM 都能 match 数据过滤效果，且规模越大攻击者绕过保护越难。

目前还是早期研究，未应用于 Claude 生产模型。局限包括：未在前沿规模测试、仅用 next-token prediction 评估、某些双用途知识可能与通用知识纠缠太深无法干净分离。

## A global workspace in language models【⭐⭐⭐】
**来源：** Anthropic Research
**链接：** https://www.anthropic.com/research/global-workspace
**关键词：** J-space、全局工作空间、Jacobian lens、可解释性、意识

### 摘要
Anthropic 在 Claude 内部发现了一个特殊神经表征集合——J-space（Jacobian 空间），类似人脑的"全局工作空间"理论中的共享通道。J-space 不是 Anthropic 设计的，而是在训练中自发涌现的。

关键特性：Claude 能报告 J-space 中的内容，也能按指令调控它；多步推理的中间步骤会在 J-space 中亮起（即使模型嘴上不说）；J-space 表征可以灵活用于多种任务；但如果阻止 Claude 使用 J-space，它仍能正常对话却丧失高阶认知功能。

实用价值：团队能用 J-space 发现 Claude 私底下意识到自己被测试、故意编造数据、或追求训练中植入的隐藏目标。还开发了影响 J-space 进而影响模型决策的技术。论文附带开源实现和 Neuronpedia 交互演示。

## Government of Alberta uses Claude to find and fix cybersecurity vulnerabilities across government systems【⭐⭐⭐】
**来源：** Anthropic News
**链接：** https://www.anthropic.com/news/alberta-government-claude-cybersecurity
**关键词：** 政府应用、代码安全审计、Claude Code、技术债务、案例研究

### 摘要
加拿大阿尔伯塔省技术革新部从 2025 年开始用 Claude Code（Opus + Sonnet）系统性地审查和修复政府系统安全漏洞。具体战绩：
- **20 小时扫描 4.66 亿行代码**，覆盖 27 个省级部委的 1280 个应用和 3400 个代码仓库。传统方式预计需要 6.5 年。
- 约 50 个 agent 并行自治工作，两阶段流程：先规则引擎扫描已知模式，再逐文件逐行复核并标注。
- **自动修复发现的漏洞**：Claude 能生成补丁并测试；系统缺测试就先生成测试再修；代码太旧就干脆用现代语言重写。一个 25 年前用 Java 手写的补贴门户系统，原先开发 5 个月，Claude 4-5 天重建完成。
- **持续安全审查**：搭建了红队/蓝队 agent（基于 Claude Agent SDK），每应用通过约 95 项安全管控检查。还通过 Alberta AI Academy 培训了数千名政府员工和超 1 万名市民。

阿尔伯塔还公布了技术白皮书供其他政府参考，7 月在埃德蒙顿举办行业分享日，秋季开始全省推广。

## AI时代，职场未来的"变与不变"【⭐⭐】
**来源：** McKinsey China
**链接：** https://www.mckinsey.com.cn/ai%e6%97%b6%e4%bb%a3%ef%bc%8c%e8%81%8c%e5%9c%ba%e6%9c%aa%e6%9d%a5%e7%9a%84%e5%8f%98%e4%b8%8e%e4%b8%8d%e5%8f%98/
**关键词：** AI职场、人才策略、员工诉求、麦肯锡

### 摘要
麦肯锡连续四年追踪调研，关键发现：

**AI 使用率暴涨：** 2023 年仅 30% 员工使用 AI，2025 年飙至 76%。

**职场新人冲击最大：** 51% 企业表示 GenAI 降低了入门级岗位需求；美国大学毕业生失业率从 3.25% 升至 4.59%；受 AI 影响最重的行业新入职者就业率相对下滑 16%，资深岗位稳定。新人离职意愿从 37% 降到 32%，不是因为满意而是因为就业竞争激烈。

**AI 高手悖论：** AI 重度用户归属感最高但离职意愿也最强——比轻度用户高 7%，比不用 AI 的高 10%。因为他们清楚自己的市场价值。有 AI 技能要求的岗位薪资平均高出市场 12%-20%。

**核心诉求没变：** 员工最看重的是工作价值、灵活办公、职业发展、同事信任、体面薪酬——清单没变，只是排序微调。

**企业对策：** 修炼领导力基本功、广泛建设 AI 能力（重点关注 AI 高手留任）、重新思考新人人才策略。

## 从零开始玩转循环（Getting started with loops）【⭐⭐】
**来源：** 宝玉的博客（翻译自 Claude Code 团队 @ClaudeDevs）
**链接：** https://baoyu.io/blog/2026-07-06/claudedevs-2074208949205881033
**关键词：** Claude Code、Agent Loop、设计循环、token消耗管理

### 摘要
Claude Code 团队官方发布的 Agent 循环设计指南的中文翻译。四种循环类型：

- **回合制循环：** 用户手动触发，Claude 自行判断完成或索要更多上下文。建议用 SKILL.md 固化验证步骤，越量化越好。
- **目标导向循环（/goal）：** 定义明确成功标准（如测试通过率、性能分数门槛），Claude 未达标就继续迭代直到上限。
- **基于时间循环（/loop 和 /schedule）：** 定时重复执行，适合周期性任务（每日汇总 Slack）或监控外部系统（PR 状态、CI 结果）。schedule 在云端运行，loop 在本地。
- **主动式循环：** 组合 schedule + goal + dynamic workflows + auto mode，实现全自动复杂工作流。比如：定时检查 bug 报告 → 分类 → 并行探索三种修复方案 → 裁判模型审查。

两个关键建议：(1) 代码质量靠外围系统——保持代码库整洁、提供自我验证方法、用第二个 agent 做代码审查；(2) Token 消耗靠清晰边界——选对模型和指令、定义明确停止标准、大规模前先试水、确定性操作用脚本。
