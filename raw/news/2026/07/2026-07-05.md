## 字节跳动开源 deer-flow：76k Star 的 SuperAgent 框架【⭐⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/bytedance/deer-flow
**关键词：** 字节跳动、SuperAgent、长周期、sandbox、Agentic

### 摘要
字节跳动开源的 deer-flow 是一个长周期（long-horizon）SuperAgent 框架，集研究、编程和内容创作为一体。通过 sandbox、记忆系统、工具链、skills、子代理和消息网关的组合，能处理从几分钟到数小时不等的各级任务。2025年5月创建至今已获76k星，是当前最受关注的 Agent 框架之一。技术栈覆盖 Python 和 TypeScript，支持 LangChain/LangGraph 生态。

对比：相比 Anthropic 的 Claude Code（136k星，更聚焦终端编码）和 stablyai/orca（12k星，并行 agent 管理），deer-flow 的定位更偏向通用长周期任务编排。

## OpenBMB VoxCPM2：免分词器的多语言 TTS 突破【⭐⭐⭐】
**来源：** Github Trending Daily
**链接：** https://github.com/OpenBMB/VoxCPM
**关键词：** TTS、语音合成、多语言、声线克隆、免分词器

### 摘要
OpenBMB（清华团队）发布 VoxCPM2，一个 tokenizer-free 的 TTS 模型，支持多语言语音生成、创意声线设计和高度逼真的声线克隆。33k星。免分词器架构意味着不需要将文本转为 token 再合成，端到端直接生成语音。支持中英等多语言，在语音自然度和声线还原度上有显著提升。对比 Lightricks LTX-2（8k星，音视频联合生成），VoxCPM2 更专注语音本身的质量。
