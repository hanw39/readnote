## Tino Cuéllar 加入 Anthropic 担任首席全球事务官【⭐⭐】
**来源：** Anthropic News
**链接：** https://www.anthropic.com/news/tino-cuellar
**关键词：** Anthropic 人事任命、AI政策与治理、全球政府关系

### 摘要
Mariano-Florentino (Tino) Cuéllar 于 8 月 4 日正式加入 Anthropic，出任公司首位 Chief Global Affairs Officer，统管全球政策、国际战略和政府关系。Cuéllar 的履历横跨法律、技术、国际安全和公共机构多个领域：曾任卡内基国际和平基金会（Carnegie Endowment for International Peace）主席，该机构在 20 个国家设有学者；此前担任加州最高法院大法官，判决涉及技术隐私、国际协议和三权分立等议题；曾在斯坦福大学领导 Freeman Spogli 国际研究所并联合主持该校国际安全与合作中心。他还在三届总统任期内服务于白宫和联邦机构，并担任总统情报顾问委员会成员。

Cuéllar 自 2026 年 1 月起担任 Anthropic 长期利益信托基金的受托人，现已辞去信托职务加入公司。他在声明中表示"民主国家必须为 AI 技术的发展设定规则"，强调当前是 AI 治理的关键拐点。Daniela Amodei 评价他是"帮助公共机构应对变革的最佳人选"。此次任命发生在 Anthropic 与全球各国政府互动日益密集的节点——AI 对经济、安全和社会的冲击正在被各国领导人热议。

**总评：** 这是一次典型的高规格"旋转门"任命。Cuéllar 的独特之处在于同时拥有司法（大法官）、学术（斯坦福 HAI）、国际政策（卡内基）和政府（白宫/情报委员会）四重背景，对 Anthropic 正在面临的全球监管博弈来说，这种复合资历几乎无可替代。值得关注的是他从信托受托人转为全职高管，意味着 Anthropic 的长期治理架构也在发生实质性变化。

## Google Cloud API Gateway 推出统一 AI 模型路由功能【⭐⭐】
**来源：** Google AI
**链接：** https://developers.googleblog.com/a-unified-api-for-ai-model-routing/
**关键词：** Google Cloud、API Gateway、模型路由、多模型统一API、OpenAI兼容

### 摘要
Google Cloud API Gateway 新增模型路由（Model Routing）功能（Public Preview），开发者可以通过 OpenAPI 3.x 规范配置虚拟模型名称到具体后端服务的映射，无需硬编码 endpoint 或自行维护开源代理。Gateway 作为 serverless 入口层，接受标准 OpenAI 兼容格式的请求，自动将 payload 转码为目标模型的原生 schema，动态路由到 Gemini、Claude、OpenAI OSS-GPT 等不同模型。

这意味着开发者可以用一套统一的 API 调用来切换不同厂商的模型，不需要修改客户端代码。该功能由 Product Manager Mak Ahmad 和 Software Engineer Sanjay Pujare 发布。

**总评：** 这个东西的实质是 Google 在云端提供了一个"模型路由器"——但放在 API Gateway 里而非独立产品，说明 Google 的定位是让模型路由成为基础设施层的一个内置能力，而非需要额外集成的中间件。配合 OpenAPI 声明式配置和无服务器架构，降低了多模型策略的门槛。不过这也引发一个问题：当所有流量都经过 Google Cloud 的路由层时，Google 对模型流量的可见性会大大增加——这是一把双刃剑。
